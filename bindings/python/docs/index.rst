ptiff — Python bindings for libptiff
====================================

Python bindings for *libptiff*, generated by SWIG from the language-agnostic
C ABI (``libptiff_c``). This is the raw C-ABI surface, not idiomatic Python:
functions and types are named and shaped exactly as SWIG emits them from
``bindings/swig/ptiff.i`` (see the "alles in SWIG" migration notes in
``bindings/swig/README.md``). ``_ptiff`` is a compiled C extension linked
against ``libptiff_c``; it is not pure Python and needs a matching build
(``make -C ../swig python``) before it can be imported.

Quick start
-----------

Build the extension against a ``libptiff_c`` build/install (either via
``PTIFF_C_LIB_DIR`` or ``PKG_CONFIG_PATH``):

.. code-block:: console

   $ PTIFF_C_LIB_DIR=/path/to/libptiff_c/build/dir make -C ../swig python
   # or, against an installed prefix:
   $ PKG_CONFIG_PATH=/where/ever/lib/pkgconfig make -C ../swig python

This regenerates ``src/ptiff.py`` and compiles ``src/_ptiff.so``. Then
install/run against ``src/`` on ``PYTHONPATH`` (see ``pyproject.toml``'s
``[tool.pytest.ini_options]``) or via ``pip install .`` / ``uv pip install .``.

Basic usage:

.. code-block:: python

   import ptiff

   print(ptiff.ptiff_runtime_version())
   print(ptiff.ptiff_backend_names())

   desc = ptiff.ptiff_image_descriptor()
   desc.width = 10
   desc.height = 20
   desc.pixel_type = ptiff.PTIFF_PIXEL_UINT16
   desc.channel_count = 3
   desc.has_gsd = 1
   desc.gsd = 0.5

   img = ptiff.ptiff_image_create(desc)
   print(ptiff.ptiff_image_width(img), ptiff.ptiff_image_height(img))
   ptiff.ptiff_image_destroy(img)

Development
-----------

The repository uses ``uv`` for dependency management, ``hatchling`` for
builds, and ``ruff`` / ``mypy`` / ``sphinx`` for linting, type-checking and
docs:

.. code-block:: console

   $ uv sync --all-extras --dev
   $ uv run ruff check .
   $ uv run ruff format . --check
   $ uv run mypy .
   $ uv run pytest
   $ uv run sphinx-build -b html docs docs/_build/html
