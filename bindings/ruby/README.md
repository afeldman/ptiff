# PTiff — Ruby bindings for libptiff

Ruby [gem](https://guides.rubygems.org/what-is-a-gem/) for
[libptiff](../..): raw SWIG output over the language-agnostic C ABI
([`bindings/c`](../c), built as `libptiff_c`). `lib/ptiff.{bundle,so}` is a
compiled native extension linked against `libptiff_c` — generated by
[`bindings/swig`](../swig)'s `ptiff.i` (`make -C ../swig ruby`), not
hand-written. This is the **promoted, official** Ruby binding (see the
"alles in SWIG" migration notes in
[`bindings/swig/README.md`](../swig/README.md#planned-migration)); the
former pure-`Fiddle` wrapper is deleted.

Functions and types are named and shaped exactly as SWIG emits them from the
C ABI (`Ptiff::ptiff_image_create`, `Ptiff::PTIFF_PIXEL_UINT16`,
`Ptiff::Ptiff_image_descriptor` as a class with public accessors, ...), not
an idiomatic Ruby API.

## Structure

```
bindings/ruby/
├── ptiff.gemspec            # gem metadata (name, version, files)
├── Gemfile                  # development deps (minitest, rake)
├── Rakefile                 # `rake test` / `rake build`
├── lib/
│   ├── ptiff.{bundle,so}    # generated: compiled SWIG extension (gitignored)
│   ├── ptiff_wrap.c         # generated: SWIG C wrapper source (gitignored)
│   └── ptiff/version.rb     # hand-authored: PTiff::VERSION (gem metadata only)
└── test/
    ├── test_version.rb      # ported: version surface
    ├── test_logger.rb       # ported: logger surface
    ├── test_backend.rb      # ported: backend registry
    ├── test_error.rb        # ported: error/pixel-type/compression-kind ordering
    ├── test_image.rb        # ported: Image domain type
    ├── test_sink.rb         # ported: sink/source tile write+read
    └── test_roundtrip.rb    # ported: full write→read round-trip
```

## Build libptiff_c, then regenerate the extension

Build the shared `libptiff_c` once from the repo root:

```bash
cargo build -p ptiff-c --release
```

Then regenerate `lib/ptiff.{bundle,so}` against it (from `bindings/swig`):

```bash
# in-tree dev (from bindings/swig): builds against target/release by default
make -C ../swig ruby

# or explicitly against a build output:
PTIFF_C_LIB_DIR=$PWD/../../target/release make -C ../swig ruby

# or against an installed prefix:
PKG_CONFIG_PATH=/where/ever/lib/pkgconfig make -C ../swig ruby
```

The built `libptiff_c.dylib` embeds an `@loader_path`/`$ORIGIN` rpath so
it resolves the transitive Rust core in the same directory — no
`DYLD_LIBRARY_PATH`/`LD_LIBRARY_PATH` needed at runtime; `make ruby` bakes
the same rpath into the compiled extension.

## Test (with Bundler)

```bash
bundle install
bundle exec rake test   # Rakefile puts lib/ + test/ on the load path
```

Or run a single ported test file directly (mirrors what `make test` in
`bindings/swig` does):

```bash
cd test && RUBYLIB=../lib ruby test_roundtrip.rb
```

## Build / install the gem

```bash
gem build ptiff.gemspec
# local install
gem install ./ptiff-1.1.0.gem
# or with Bundler from this directory
bundle install
```

Note: the gem ships a **prebuilt, platform-specific** `lib/ptiff.{bundle,so}`
(no `extconf.rb`/native-extension build step) — build it via `make -C ../swig
ruby` for the target platform before `gem build`.

## Use

```ruby
require "ptiff"

v = Ptiff::ptiff_runtime_version
v.major, v.minor, v.patch             # => 1, 0, 1
Ptiff::ptiff_backend_names            # => "core, ..." (comma-joined string)

desc = Ptiff::Ptiff_image_descriptor.new
desc.width = 10
desc.height = 20
desc.pixel_type = Ptiff::PTIFF_PIXEL_UINT16
desc.channel_count = 3
desc.has_gsd = 1
desc.gsd = 0.5

img = Ptiff::ptiff_image_create(desc)
Ptiff::ptiff_image_width(img)         # => 10
Ptiff::ptiff_image_destroy(img)
```

## Idiomatic usage

The gem exposes two layers, mirroring the Python package `src/ptiff/`:

* low-level `Ptiff::` (from `lib/ptiff.{bundle,so}`): all `ptiff_*` functions and
  `Ptiff_*`/`PTIFF_*` structs and constants;
* idiomatic `PTiff::` classes (`Image`, `Camera`, `Tile`, `Logger`,
  `Metadata`) that wrap the low-level surface.

Prefer the idiomatic classes:

```ruby
require "ptiff"

# Read
img = PTiff::Image.open("a.tif")
tile = img.read_tile(0, 0)
img.close

# Write (with an optional persisted camera)
cam = PTiff::Camera.new(focal_length_x: 700.0, principal_x: 64.0)
img = PTiff::Image.create("out.tif", 32, 32, tile_width: 16, tile_height: 16, camera: cam)
img.write_tile(0, 0, "\x00".b * img.tile_byte_size)
img.close

# Metadata (no live handle)
m = PTiff::Metadata.new("a.tif")
m.field("ptiff.camera.model") # => "pinhole"

# Logger
log = PTiff::Logger.new
log.level = PTiff::Logger::ERROR
log.error("boom")
```

## Covered API

Version, error codes, logging, the backend registry, `Image` domain type
plus its descriptor/value types, and tile read/write (`ptiff_sink_*` /
`ptiff_source_*`) — see `test/` for the full ported surface.
