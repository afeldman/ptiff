# PTIFF -- API Documentation {#mainpage}

<center>
**PTIFF** — *Planetary Terrain-sensor Image File Format — reference implementation*
</center>

The PTIFF reference implementation is a **Rust workspace** (see
`PTIFF-1.0-RUST-CORE-PLAN.md` and `RUST-WORKSPACE.md`): `ptiff-core` holds the
single maintained core domain model and storage/I/O layer, `ptiff-rust` adds an
idiomatic, ergonomic Rust frontend (`ptiff`), `ptiff-cli` ships the `ptiff`
command-line tool, and `ptiff-c` exposes the stable C ABI (`ptiff_*` /
`libptiff_c`) over the core. There is no C++ in the stack.

The public Rust API is documented with **rustdoc** — this Doxygen site
complements it with **concept/overview pages** (below) and the **C ABI**
documentation generated from `target/ptiff_c.h` (cbindgen-derived from the
`extern "C"` surface in `crates/ptiff-c`).

## Getting started

```bash
# Build the whole workspace and run all tests.
cargo build --workspace --all-features
cargo test --workspace --all-features

# The idiomatic Rust frontend `ptiff` is what normal Rust callers use:
cargo run -p ptiff-cli -- info /path/to/image.tif
```

The C ABI header `target/ptiff_c.h` is generated by cbindgen from the
`extern "C"` signatures in `crates/ptiff-c` during `cargo build -p ptiff-c`.
The C ABI reference below is built from that header.

## How to use this documentation

- **Related pages / Modules** — high-level walkthroughs (see Contents above).
- **C ABI reference** — every `ptiff_*` function and `ptiff_c_*` value type,
  auto-generated from the comments in `target/ptiff_c.h`.
- **Rust API** — generated with `rustdoc`; run
  `cargo doc --workspace --no-deps --open`.

## Project layout

| Path                          | Contents                                      |
| ----------------------------- | --------------------------------------------- |
| `crates/ptiff-core/`          | Single maintained Rust core (domain model + storage/I/O). |
| `crates/ptiff-rust/`          | Idiomatic Rust frontend (`ptiff`) + examples. |
| `crates/ptiff-cli/`           | `ptiff` command-line tool.                    |
| `crates/ptiff-c/`             | C ABI layer (`ptiff_*`, generates `ptiff_c.h`). |
| `bindings/`                   | PDS-adjacent language bindings (Go, Python, Ruby, Octave, MCP). |
| `rfcs/`                       | PTIFF standard RFCs                           |
| `specification/`              | Normative format specification                |
| `docs/`                       | Design specs, plans and this documentation    |

## The C ABI surface

The C ABI lives exclusively in the `ptiff-c` crate; the core ships
**no** `#[no_mangle]` and forbids `unsafe_code`. The stable `ptiff_*`
functions cover versioning, the image bridge, camera/CRS metadata, the
pixel bridge, the logger, and error codes — see the C ABI reference pages
for the full enumeration.
