# PTIFF Specification — Photometry Domain

The Photometry domain covers radiometric / photometric calibration of a planetary image.
Today it is **conceptual** (no dedicated private tag); photometric layer products are carried
via the generic Scientific-Layers tag (65004, `ptiff.layers.*`).
